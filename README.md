# Towards-autonomic-computing-systems-working-final-project-

This repo contains the research artefacts, theoretical models, and
simulation work associated with my final-year project.

## Project Overview
Autonomic computing systems aim to exhibit self-configuring, self-healing,
self-optimising, and self-protecting behaviour. Fully autonomic systems do not
yet exist in practice. This project explores how near-autonomic behaviour can be
modelled using discrete dynamical systems and random Boolean networks. (working abstract)

The work is primarily theoretical, supported by simulation-based experiments.

## Repository Structure
- `/timeline` – chronological research notes documenting project evolution
- `/literature` – summaries and analysis of key academic sources
- `/theory` – formal models and mathematical foundations
- `/methodology` – system assumptions and simulation design
- `/experiments` – planned and preliminary simulation results
- `/src` – simulation and analysis code
- `/dissertation` – outlines and draft material
